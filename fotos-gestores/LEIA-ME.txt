Depois, na raiz do projeto:

  npm run fotos:bucket    (uma vez: cria o bucket privado)
  npm run fotos:enviar    (envia; reduz para 512x512 com recorte central)

Pode rodar fotos:enviar de novo quando trocar uma foto: ela é substituída.
